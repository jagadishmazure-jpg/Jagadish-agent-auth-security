# Glossary

| Term | Meaning |
|---|---|
| JWT | JSON Web Token (RFC 7519), here used as access tokens |
| JWKS | JSON Web Key Set (RFC 7517) |
| DPoP | Demonstrating Proof-of-Possession (RFC 9449) |
| mTLS-bound token | Certificate-bound access token (RFC 8705) |
| PKCE | Proof Key for Code Exchange (RFC 7636), required by OAuth 2.1 |
| OBO | On-behalf-of; Entra's form of RFC 8693 token exchange |
| BFF | Backend for frontend |
| `tv` | Token version claim for stale-claim defence |
| MCP | Model Context Protocol |
| A2A | Agent-to-agent |
